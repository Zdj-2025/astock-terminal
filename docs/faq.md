# FAQ

**Q：缠论/晨报/综合评分报网络错误？**
tushare/akshare 网络波动所致，页面会降级提示；K线/波浪/持仓页走本地 parquet 不受影响，稍后重试即可。

**Q：晨报为什么慢（1-3分钟）？**
内部逐票走 tushare 财报季历（限速）。生成后当日缓存，重复打开秒出。

**Q：改了前端代码页面没变？**
`npm run build` 后强制刷新（hash 路由不自动重载新构建）。

**Q：怎么换端口/对外访问？**
`.env` 里 `PORT=...`、`HOST=0.0.0.0`（注意自行承担暴露风险，建议加反代+鉴权）。

**Q：数据会自动更新吗？**
不会——本工具红线是"看板只读"。更新由 crontab 调 scripts/ 命令完成（见 quickstart）。

**Q：支持港美股吗？**
当前仅 A 股（含 ETF/指数）。数据层按 parquet 抽象，理论上可扩展。
